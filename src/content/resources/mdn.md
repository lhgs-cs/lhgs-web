## 为什么推荐它

如果你在写网页，遇到"这个属性到底怎么用"的问题，先别去搜博客。

MDN 是 Mozilla 维护的 Web 标准文档，**HTML / CSS / JavaScript 的每一个特性都有规范级的说明**，而且带浏览器兼容性表格。搜到的博客经常是几年前的写法，MDN 会告诉你这个特性现在还能不能用。

## 适合谁

- 刚开始学 HTML/CSS，想知道某个标签或属性是干嘛的
- 写 JS 时不确定某个 API 的参数和返回值
- 想确认某个 CSS 属性在 Safari 上支不支持

## 怎么用

不要从头读到尾，那样效率很低。**遇到问题带着关键词去搜**，比如"flex align-items"。

每个页面右侧的"浏览器兼容性"表格是最有价值的部分之一 —— 它直接告诉你这个特性在哪些版本可用。

## 一个提醒

MDN 的示例都是英文语境。刚开始可能会有点吃力，但技术词汇翻来覆去就那些，看两周基本就顺了。中文版是社区翻译的，部分页面可能滞后于英文版。
